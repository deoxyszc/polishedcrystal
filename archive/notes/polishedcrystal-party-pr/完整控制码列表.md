# 完整文本控制码与字节占用表

基线：ea222ef159af9c58fb9cdcd2e9ef3d0d236ac503
范围：文本脚本、字符串、ZH私有流。不是地图事件或战斗动画脚本操作码；它们有独立入口。

## 读取规则与证据边界

所有数值均为十六进制。下表完整覆盖256字节，但并非256个都是操作码；字符/图块、缩写、控制码必须区分。
原版未分配不等于安全可用：旧PlaceString遇到低值会停止，且0A–0E已有中文扩展。
参考实际控制由home/text.asm的CheckDict及@终止分支提取；JSON保留全部声明和行号，包括日文别名。DFS首/尾范围仅为dfs_constants定义，不覆盖优先的CheckDict；重叠值必须按实际分派处理。
Huffman压缩内容是位流；5D CTXT切入解压器，不能用压缩字节出现频率决定文本控制码是否可分配。
此处为静态定义/调用核对，不宣称逐控制码游戏路径全部执行过。参数内的字节不重新识别为控制码。

## 抛光外层文本脚本指令及参数

|码|宏/含义|后续数据|处理器|
|---|---|---|---|
|00|text_start / START|进入文本读取；不是固定长度参数|TextCommand_START|
|01|text_ram / RAM|LE16 RAM地址|TextCommand_RAM|
|02|text_promptbutton / WAIT|无|TextCommand_PROMPT_BUTTON|
|03|text_asm / ASM|后续可执行代码，不作字符解析|TextCommand_ASM|
|04|text_decimal / NUM|LE16地址＋1字节，高4位字节数、低4位位数|TextCommand_DECIMAL|
|05|text_pause / PAUSE|无|TextCommand_PAUSE|
|06|text_sound / SOUND|1字节音效号|TextCommand_SOUND|
|07|text_today / DAY|无|TextCommand_DAY|
|08|text_far / FAR|BE16地址＋bank；地址bit15表示farend|TextCommand_FAR|
|09|text_plural / PLURAL|无|TextCommand_PLURAL|
|52 / 53 / 54|DONE / text_end / PROMPT|外层遇到任一均终止；先于命令分派检测|CheckTerminatorChar|

## 当前ZH各入口的具体格式
- 外层0A描述符：后接LE16起始地址＋LE16结束地址，固定bank80；由ZhDispatchText解析。
- E1字符逃逸0A：后接2个最高位为1的7bit负载字节，还原14bit临时glyph ID；由ZhDecodeGlyph解析，不能当DFS码。
- ZH私有对话0B/0C：动态玩家/劲敌名字，无附加字节；0D：bank＋LE16 RAM地址；0E：两个BE16分片ID。
- ZH私有02等待、52完成、53串结束、54提示、55滚动、56下一行、57底行、59段落；无固定字节参数。
- 引擎ZH_TOKEN_END/LITERAL/GLYPH/CONTROL的0/1/2/3是函数返回类型，不是ROM文本控制码，不占编码空间。
