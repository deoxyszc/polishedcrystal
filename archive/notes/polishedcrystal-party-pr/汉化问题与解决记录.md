# 汉化问题与解决记录

更新：2026-09-23。按影响层级排列，不按发现时间排列。一级影响公共设计与算法，二级影响局部页面；工程流程单列。层级不代替验证状态，未解决项明确标注。当前进度见[交接文档](新会话交接.md)。仅本地维护。

## 一级：架构、内存与公共算法

| 问题 | 解决方案／当前处理 |
|---|---|
| **窗口备份开销过大，保存菜单栈溢出** | 固定6字节改为静态2／动态6字节；用属性bit4标记，写前清原位、恢复去标记；精确预检记录及头部容量。不扩容、不借bank4。 |
| **英文输出与中文缓存共用显存，回退乱码** | 原版英文PlaceString接入字体敏感的动态缓存，保留8×8单格语义；绕过入口的直接写图块仍待核对。 |
| **页面独占显存、整句预合成导致资源互相覆盖** | 删除旧路径，统一单字分片、公共组合与缓存；全场景资源保护仍待验证。 |
| **页面配置耦合，一处调整影响其它界面** | 只用LOCALE_ZH；各页面独立编译期配置，共用输出机制，不共用页面坐标。 |
| **中文字形、数字与符号无法在同一图块内衔接** | 按完整图块划分区域，编译单元级组合；真实数字保留原格式化入口，不生成整句图片。 |
| **误认为其它WRAM bank可以直接借用** | 按调用链核对地图、图鉴和存活窗口的生命周期。当前用压缩解决容量，bank4复用方案未采用。 |
| **文本提取丢失上下文、动态占位或分支语义** | 按profile导出完整消息，保留控制码与占位，导入校验来源hash及覆盖；图片资源另处理。 |
| **预览数据未接入真实游戏机制** | 正式页面读取真实ID、名字、HP、等级和状态；测试映射与强制值只留隔离副本。 |

## 二级：局部排版与视觉修正

| 问题 | 解决方案／当前处理 |
|---|---|
| 汉字、字母和数字基线不齐 | 各自配置字形偏移，按页面对齐字格底部。 |
| 名字、取消和下框重叠 | 转换参考的上下半图块锚点，给名字、取消、框线分开区域。 |
| 四字名字挤占等级 | 紧凑L去冒号、等级右对齐；100级省略L，接受已确认的少量侵入。 |
| HP数字离血条太远、等级未贴血条 | HP数字下移2px，等级右对齐；四字以内长血条，五字短血条。 |
| 页面切换后图标颜色或边框不对 | 复用原美术，恢复对应属性和调色板，检查完整中英画面；显存内容被覆盖则归一级问题。 |
| 选中图标遮挡名字 | **未修复，用户暂缓**；不再根据字体或图标宽度猜测原因。 |

## 工程流程：验证与资料管理

| 问题 | 解决方案／当前处理 |
|---|---|
| 静态叠图裁错像素或元素错位 | 核准裁剪与整组坐标；叠图只作方案预览，最终用实际ROM同场景对照。 |
| 构建通过被当成全部可玩 | 构建、CPU、画面、导航分别记录；用同存档重放旧版失败路径，局部通过不等于峰值认证。 |
| 增量构建、旧report或旧ROM误导验证 | 隔离普通/debug构建，核对当前ROM hash和配套sym/map。 |
| 存档缺失、文件名与进度不符 | 稳定目录、时间戳、SHA和只读冷备；原版推进，触发前备份并核对事件。 |
| GUI按键未生效、固定回放停错界面 | 核实窗口焦点与阶段画面；CLI与GUI分开，换ROM后重新校准。 |
| 历史PR覆盖当前事实 | 以当前代码与合并状态为准；撤销的方案不计完成、不直接恢复。 |

### 未采用方案与核对结论

- 参考汉化的额外编码栈复用bank4移动新闻脚本区域；正常地图未见新闻入口调用。抛光bank4则用于大地图属性和图鉴，不能直接照搬。
- 若借用bank4，Start进入图鉴、获得新物种介绍、CloseSubmenu先读地图后退栈等路径需要协调。该方向只做分析，当前并未实施。详见 /Users/zhaoc/source/polishedcrystal-vram-audit/bank4窗口生命周期排查.md。
- SetUpMenu本身会重绘菜单，但其调用前通常由ExitMenu恢复菜单参数。不能把“可重画文字”推成“父窗口状态都可以丢弃”。
- 参考DFS的汉字为12×12，调用锚点指下半图块；当前指上半图块，差8px。图块留白与字体墨迹是两件事。
- 两版图标都有选中右移8px。小锯鳄对照资源均16×16，抛光版纵基准低2px；静态叠图不模拟实际精灵优先级，不能凭叠图断言参考游戏的最终遮挡结果。
- 临时目录中的历史存档有创建成功日志，缺失原因没有证据。已重建爷爷家门口、屋内电话前、劲敌战前三节点；不需要额外保存电话结束后作为独立排版测试节点。
